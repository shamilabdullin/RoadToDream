# 01. Правильная скобочная последовательность

Источник: LeetCode 20 «Valid Parentheses». Классика live-coding на тему «стек».

## Условие
Дана строка `s` из символов `()[]{}`. Вернуть `true`, если скобки расставлены правильно:
- каждая открывающая закрыта скобкой **того же типа**;
- скобки закрываются **в правильном порядке** (`"([)]"` — неверно);
- у каждой закрывающей есть парная открывающая.

## Примеры
```ts
isValid("()")      // true
isValid("()[]{}")  // true
isValid("([{}])")  // true
isValid("(]")      // false
isValid("([)]")    // false
isValid("((")      // false
isValid(")")       // false
isValid("")        // true
```

## Ограничения
- `0 <= s.length <= 10^4`
- В строке только символы `()[]{}`.
- Цель: O(n) по времени.
