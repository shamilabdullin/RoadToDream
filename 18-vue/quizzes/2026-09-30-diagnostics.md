## 1. Реактивность Vue 3: ref / reactive, почему не нужен сеттер
**Ответ ученика:** механизм не помнит; ref — аналог state в React; reactive — не знает; почему не нужен сеттер — не знает.
**Разбор (объяснено):** Vue 3 — Proxy: get → track (запомнить зависимость рендера/эффекта), set → trigger
(перезапустить зависящее). Само присваивание — сигнал, поэтому сеттер не нужен; нет массивов зависимостей.
React — иммутабельно, setState → перезапуск компонента + diff VDOM.
ref — обёртка { value } для любых значений (Proxy не оборачивает примитивы), .value в JS, в шаблоне разворачивается.
reactive — только объекты; нельзя переприсвоить целиком, деструктуризация теряет реактивность (toRefs).
Рекомендация — ref по умолчанию. Vue 2: Object.defineProperty не видел новые свойства и arr[i] = x → Vue.set.
**Оценка:** 1.
